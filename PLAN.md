# План: кнопки «О чем статья?», «Тезисы», «Пост для Telegram»

Основание: [PROJECT.md](./PROJECT.md).

Приложение получает URL англоязычной статьи, парсит её и по нажатию кнопки подключает AI для генерации нужного вида ответа в блоке «Результат».

**Текущее состояние:** парсинг и кнопка «Перевести» работают; три кнопки действий — заглушки в `referent-app.tsx`.

---

## 1. Зафиксировать требования к каждой кнопке ✅

**Статус:** выполнено. Подробности — в [REQUIREMENTS.md](./REQUIREMENTS.md).

Краткая сводка:

| Кнопка | Что должно появиться в «Результат» |
|--------|-------------------------------------|
| **О чем статья?** | Краткий пересказ статьи на русском (не полный перевод): главная мысль, контекст, выводы |
| **Тезисы** | Список ключевых мыслей статьи на русском (5–10 пунктов) |
| **Пост для Telegram** | Готовый к публикации пост на русском (до ~1000 символов), в конце — ссылка на источник |

Общий сценарий для всех трёх кнопок (как в PROJECT.md):

1. Пользователь вводит URL.
2. Нажимает одну из кнопок.
3. Приложение парсит статью.
4. AI генерирует ответ нужного типа.
5. Ответ показывается в блоке «Результат» с соответствующим бейджем.
