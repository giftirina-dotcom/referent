# Требования к кнопкам действий

Основание: [PROJECT.md](./PROJECT.md), этап 1 [PLAN.md](./PLAN.md).

Документ фиксирует ожидаемое поведение трёх кнопок: **«О чем статья?»**, **«Тезисы»**, **«Пост для Telegram»**.  
Кнопка **«Перевести»** в этот документ не входит — её поведение остаётся без изменений.

---

## Общий сценарий

Для каждой из трёх кнопок:

1. Пользователь вводит URL англоязычной статьи.
2. Нажимает одну из кнопок действий.
3. Приложение загружает и парсит статью (`/api/parse`).
4. Приложение отправляет текст статьи в AI с инструкцией, соответствующей нажатой кнопке (`/api/translate`).
5. В блоке **«Результат»** отображается ответ нужного типа с соответствующим бейджем.

Если URL не указан или некорректен — показывается сообщение об ошибке под полем ввода.  
Если статью нельзя загрузить или распарсить — в блоке «Результат» показывается дружелюбное уведомление (без красной ошибки под URL).

## «О чем статья?» (`summary`)

### Назначение

Дать пользователю быстрое понимание содержания статьи без чтения полного перевода.

### Что должно появиться в «Результат»

- Перевод **заголовка** статьи на русский.
- Раздел **«О чём статья»** — краткий пересказ своими словами на русском языке.

### Формат ответа (Markdown)

```markdown
# Перевод заголовка

## О чём статья

2–5 предложений: главная мысль, контекст, ключевые выводы.
```

### Обязательно

- Язык ответа — **русский**.
- Текст — **сжатое изложение**, не дословный перевод абзацев.
- Сохранение смысла оригинала.

### Запрещено

- Полный перевод текста статьи.
- Раздел «Тезисы», «Перевод» или иной формат, не относящийся к краткому содержанию.
- Комментарии модели вроде «Вот краткое содержание:».

## «Тезисы» (`theses`)

### Назначение

Выделить главные мысли статьи в виде удобного списка для быстрого просмотра.

### Что должно появиться в «Результат»

- Перевод **заголовка** статьи на русский.
- Раздел **«Тезисы»** — маркированный список ключевых мыслей на русском.

### Формат ответа (Markdown)

```markdown
# Перевод заголовка

## Тезисы

- Первый тезис — одно законченное предложение.
- Второй тезис.
- … (всего 5–10 пунктов)
```

### Обязательно

- Язык ответа — **русский**.
- **5–10** пунктов (если материала мало — меньше, но не один абзац вместо списка).
- Каждый тезис — **одна законченная мысль** в одном предложении.

### Запрещено

- Полный перевод или пересказ статьи абзацами.
- Раздел «О чём статья» или готовый пост для Telegram.
- Нумерованный список там, где достаточно маркированного (предпочтение — `-`).

## «Пост для Telegram» (`telegram`)

### Назначение

Получить текст, который можно сразу скопировать и опубликовать в Telegram-канале или чате.

### Что должно появиться в «Результат»

- **Готовый пост** на русском языке по материалу статьи.
- Пост должен быть **самодостаточным**: читатель понимает суть без доступа к оригиналу.

### Формат ответа

- **Заголовок** — первая строка поста, обязательна; цепляющий, на русском (допустимы emoji); выделить **жирным**.
- **До ~1000 символов** (включая пробелы и переносы).
- После заголовка — пустая строка, затем короткий **вводный абзац** (2–3 предложения).
- **2–4 ключевых пункта** списком.
- В **конце** — ссылка на **исходный URL** статьи (источник).
- По желанию — вопрос или призыв к обсуждению перед ссылкой.

Пример структуры (не жёсткий шаблон):

```
**🔥 Заголовок поста**

Короткий ввод: о чём материал и почему это важно.

• Первый ключевой пункт
• Второй ключевой пункт
• Третий ключевой пункт

А вы согласны с автором?

Источник: https://…
```

### Обязательно

- Язык ответа — **русский**.
- **Заголовок** в первой строке поста — обязателен.
- Стиль — **живой, для соцсети**, не академический пересказ.
- Текст **готов к публикации** — без пояснений от модели.
- **Ссылка на источник** в конце поста.

### Запрещено

- Полный перевод статьи.
- Пост **без заголовка** в первой строке.
- Markdown-заголовки `#` / `##` (в Telegram они не нужны; допустимы **жирный** текст и переносы строк).
- Превышение лимита ~1000 символов без необходимости.

## Поведение интерфейса (общее для трёх кнопок)

| Ситуация | Ожидаемое поведение |
|----------|---------------------|
| URL пустой | Ошибка под полем: «Введите URL…» |
| URL некорректный | Ошибка под полем: «Укажите корректный URL…» |
| Идёт обработка | Кнопки неактивны; в «Результат» — индикатор загрузки |
| Парсинг | Текст: «Загрузка и разбор статьи…» |
| Запрос к AI | Текст: «Тружусь, потерпите…» |
| Статья недоступна | Мягкое уведомление в «Результат», бейдж скрыт |
| Успех | Markdown в `BlogContent`, бейдж по типу действия |
| Быстрое переключение кнопок | В «Результат» — только ответ **последней** нажатой кнопки |
